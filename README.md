# 🔫 Project Shooter

## A Multiplayer based FPS game in threejs and typescript

## 🎯 Goals
- A complete host and client lobby system
- Multiple game modes
- Intuitive controls
- And more...

## 🛠️ Tools used
- Threejs
- Vite
- GLSL
- SocketIO

## ⚙️ For local/dev use
- **Client**
  - In first terminal, cd `client` and then `npm install`
  - For running **client** only `npm run dev`
  
- **Server**
  - In second terminal, cd `server` and then `npm install`
  - For running **server** only `npm run dev`
  - Or if you prefer running **server** and **client** at the same time then, `npm run both`
