# 🔫 Project Shooter

## A Multiplayer based FPS game in threejs and typescript

### 🎯 Goals
- A complete host and client lobby system
- Multiple game modes
- Intuitive controls
- And more...

### 🛠️ Tools used
- Threejs
- Vite
- GLSL
- SocketIO

### ⚙️ Local use
1. Client
 - cd `client` and then `npm install`
 - For running **client** only `npm run dev`
  
2. Server
 - cd `server` and then `npm install`
 - For running **server** only `npm run dev`
 - For runnning **server** and **client** both `npm run both`
